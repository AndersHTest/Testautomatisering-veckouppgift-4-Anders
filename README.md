>2. Vad är poängen med linting? <br><br>
> När du pushar din kod till github kan linting vara värdefullt att använda för att analysera din kod.
>Den kontrollerar syntax och ger förslag på hur man kan rätta till eventuella problem.
>Den hjälper dig att skriva bättre kod. Det finns olika verktyg att välja mellan. I detta projektet har jag använt "flake8".
>När jag läser om olika verktyg på internet så föreslår flera personer att testa ruff istället då det verktyget är snabbare.
>I ett större projekt kan man använda ett linting-verktyg och t.ex kräva att analysen måste vara OK för att en merge ska kunna göras.<br><br>
